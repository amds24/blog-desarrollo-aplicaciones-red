Diseño web con CSS

CSS es el lenguaje que permite definir el aspecto visual de una página web. Gracias a él podemos modificar colores, tamaños, márgenes, tipografías y la distribución de los elementos.

En este blog se utiliza una hoja de estilos externa llamada estilos.css. De esta forma, todas las páginas pueden compartir el mismo diseño sin necesidad de repetir el código CSS en cada archivo HTML.

Separar el contenido HTML de la presentación CSS facilita el mantenimiento del sitio web y permite realizar cambios de diseño de una manera más sencilla.
