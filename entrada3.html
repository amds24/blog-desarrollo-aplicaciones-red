Blog de Desarrollo de Aplicaciones en Red

Publicación de una web con GitHub Pages

GitHub Pages permite publicar páginas web directamente desde un repositorio de GitHub. Es una opción muy útil para proyectos sencillos realizados con HTML, CSS y JavaScript.

En este proyecto, los archivos del blog se almacenan en la rama principal del repositorio y GitHub Pages se encarga de mostrar el sitio web públicamente en Internet.

Gracias a este sistema, cada modificación realizada en los archivos del repositorio puede actualizarse posteriormente en la versión publicada del sitio web.
